# QRコードメーカー

URLからQRコードを生成し、PNG画像として保存する日本語のウェブアプリです。

- 任意のタイトルを画像の上または下に追加
- 日本語のタイトルとURLに対応
- タイトルをPNGのファイル名にも使用
- リセットでURL・タイトル・QRコードを消去
- URL変更時には古いQRコードを消去
- モバイル対応
- 生成処理はブラウザー内で完結（外部API・解析・追跡・保存なし）

## 手元で使う

フォルダーを展開し、index.html をブラウザーで開いてください。インストールやビルドは不要です。vendor フォルダーを含むファイル一式を同じ場所に置いてください。

## GitHubで公開する

1. GitHubで新しいリポジトリ（例：qr-code-maker）を作成します。
2. このフォルダーの中身をリポジトリの最上位にアップロードします。
3. リポジトリの Settings → Pages でブランチからの公開を選択し、main / (root) を指定します。
4. 公開が完了すると、Pagesの画面にURLが表示されます。

無料アカウントでGitHub Pagesを使う場合は、公開リポジトリを使います。入力したURLやタイトルはリポジトリには保存されません。

## 実装

HTML / CSS / JavaScript。qrcode-generator 1.4.4（MIT、Kazuhiko Arase）を同梱しています。QRの周囲は4モジュールの白い余白を確保し、各モジュールを整数ピクセルで描画します。URLは入力時の文字列をそのまま符号化します。タイトルは120文字までで、自動改行されます。

生成済みQRのリンク先を後から変更する機能はありません。
